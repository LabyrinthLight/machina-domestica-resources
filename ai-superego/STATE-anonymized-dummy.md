## Standing rules
- Habit: streak practice. Miss breaks the streak. Brief still offers today. Never overdue.
- Recurring task: obligation on a cycle. Miss → overdue every morning until done or that instance is struck.
- Homeschool miss: add Open loop "Makeup homeschool YYYY-MM-DD". Strike that day → delete that loop only. Planned skip → one-off event "Homeschool — cancelled" on that date, not a miss.
- Recurring series (event or task): change When/Starts/Cadence only when the series changes. Cancel one instance → one-off on the original date marked cancelled. Reschedule → one-off on the original date marked moved + one-off event (or makeup loop if it is work owed) at the new time. Do not spawn a second series.
- One-off open loop: dies when done. Cleanup deletes done rows.
- Recurring + done: cleanup rolls Next due to the next cycle and sets Status open.
- Undated or unclear → Dump. Daily brief never lists Dump.
- Vague report that could hit more than one row: ask once, then wait. No default write.
- Do not maintain a This week section.
- Timezone for due/overdue/events: Asia/Hong_Kong.
- Visa documentation: morning digest only in a week that has an open loop for this project due that Mon–Sun (HKT). Otherwise keep status active (not in the email). Flip to tracked that week, back to active when the week has no visa task. Digest line includes progress (N/M) from the project task list.
